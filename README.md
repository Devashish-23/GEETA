# 🕉️ Bhagavad Gita AI Chatbot

An AI-powered Bhagavad Gita chatbot built using Streamlit and NLP.

## Features

- Ask spiritual and life-related questions
- Finds relevant Bhagavad Gita verses
- Shows Sanskrit shloka
- English + Hindi meanings
- NLP-based semantic search
- Interactive chatbot UI

## Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF NLP

## Example Questions

- What is karma?
- How to control anger?
- How to stay calm?
- What is success according to Gita?

## Installation

Clone the repository:

```bash
git clone YOUR_REPO_LINK
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
